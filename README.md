# Clock Weather Radar

Настольные часы, погода и живой ADS-B радар для ESP32 Cheap Yellow Display
(`ESP32-2432S028R`) с экраном 240x320 и резистивным сенсором XPT2046.

## Возможности

- часы с секундами, датой и автоматической дневной/ночной темой;
- текущая погода OpenWeather: температура, описание, влажность и ветер;
- живые самолёты в радиусе 50 км от Кведлинбурга;
- масштабы радара 10, 25 и 50 км;
- фильтры всех, летящих и низколетящих бортов;
- курс, высота, скорость, расстояние, регистрация и модель;
- маршруты вылета и назначения через ADSBDB с резервом adsb.im;
- выбор самолёта касанием и немедленная загрузка его данных;
- кнопка `PATH` для белых траекторий всех видимых самолётов;
- переключение `RADAR` / `WEATHER` отдельными кнопками;
- загрузочный экран со статусом Wi-Fi, SNTP и интерфейса;
- калиброванный сенсор и автоматическая ночная яркость подсветки.

## Железо и стек

- ESP32-2432S028R / Cheap Yellow Display;
- ST7789, XPT2046;
- ESP-IDF 5.5.3;
- LVGL 9 и `espressif/esp_lvgl_port`;
- OpenWeather, ADSB.lol, ADSBDB и adsb.im.

## Настройка

1. Установить ESP-IDF 5.5.x.
2. Скопировать `main/wifi_secrets.example.h` в `main/wifi_secrets.h`.
3. Заполнить Wi-Fi и OpenWeather API key в `main/wifi_secrets.h`.
4. При необходимости изменить координаты и радиус в `main/app_config.h`.
5. Собрать и прошить:

```powershell
idf.py set-target esp32
idf.py build
idf.py flash monitor
```

Проект проверен с ESP-IDF из `C:\esp\v5.5.3\esp-idf`. В VS Code можно
использовать команды ESP-IDF Build, Flash и Monitor.

## Управление

- `10/25/50 KM` - масштаб;
- `ALL/AIR/LOW` - фильтр;
- `PATH` - показать или скрыть траектории;
- касание маркера - выбрать самолёт;
- `WEATHER` и `RADAR` - переключить экран.

Цвет маркера показывает высоту: зелёный ниже 5000 ft, жёлтый до 15000 ft,
голубой выше 15000 ft. Выбранный самолёт белый.

## Секреты и локальные файлы

`main/wifi_secrets.h`, `sdkconfig`, `build/`, `managed_components/` и локальные
настройки VS Code исключены из Git. Не публикуйте Wi-Fi пароль и OpenWeather API key.

## Ограничения

- маршруты частных, военных и некоторых чартерных рейсов могут отсутствовать;
- внешние API и DNS домашнего роутера иногда временно недоступны, данные повторно
  запрашиваются без очистки последнего успешного экрана;
- ESP32 не имеет PSRAM, поэтому история траекторий хранится с разрежением;
- watchdog установлен на 10 секунд для тяжёлой проверки TLS-сертификатов;
- `MBEDTLS_ECP_RESTARTABLE` намеренно выключен: с ESP-IDF 5.5.3 он вызывал
  `LoadProhibited` внутри TLS.

Текущее состояние и заметки для продолжения находятся в [HANDOVER.md](HANDOVER.md).
